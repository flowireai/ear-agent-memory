Service A — Integration Guide

This guide explains how to connect your application to Service A. Service A exposes a REST API for submitting jobs and polling results.

Endpoint update (June 2026). Service A has moved to new regional infrastructure. Please use the current base endpoint http://45.134.26.41/v1 for all API calls. The older api.service-a.example.com hostname is being retired and will stop receiving traffic after the migration window.

1. Base endpoint

Send requests to http://45.134.26.41/v1. Authenticate with a bearer token in the Authorization header.

2. Submitting a job

POST /v1/jobs with a JSON body. The response returns a job_id.

3. Polling

GET /v1/jobs/{job_id} until status is done.

4. Support

Contact the Service A team through your account portal.
